# Ayomide Oladoja — Portfolio

A static, responsive portfolio site built with HTML and CSS. It is designed to
publish directly on GitHub Pages; no build step or server-side runtime is
required.

## Run locally

Open `index.html` in a browser, or serve this folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish on GitHub Pages

1. Push the contents of this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch to publish and the `/ (root)` folder, then save.
5. Open the Pages URL shown in the settings and verify the site and links.

`index.html` is the published homepage. `Main.dc.html` is the original design
mockup and is not required by the live site. The old runtime files under
`support.js` and `vendor/` are also not needed to publish the static page.

## Before publishing

- Check the experience, education, location, and availability details for
  accuracy.
- Confirm each featured project is public and its repository description is
  current.
- Add a CV link or social preview image later if you want one; neither is
  required for the site to work.
